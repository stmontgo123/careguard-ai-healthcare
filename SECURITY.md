# Security and Data Handling

This repository is a portfolio proof of concept and documentation set.

- Use synthetic data only.
- Do not commit Protected Health Information (PHI) or electronic PHI (ePHI).
- Do not commit credentials, wallets, API keys, tokens, certificates, or private keys.
- Treat retrieved content as untrusted input.
- Enforce authorization before retrieval/generation.
- Require human approval for consequential actions.

The project demonstrates HIPAA-oriented design patterns; it is not a claim of HIPAA certification or production compliance.
